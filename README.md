# tools-promo

小工具的廣宣素材都放這裡，每次廣宣一個子資料夾，裡面是 `/promo` 流程用的 `promo/`。

| 資料夾 | 內容 | 涵蓋的工具 |
|---|---|---|
| `userscripts-3in1/` | 三個瀏覽器小工具合併廣宣 | [露天賣場自動翻頁](https://github.com/JJptt1980/ruten-autopager)、[NBA Box Score 欄位置前與排序](https://github.com/JJptt1980/nba-boxscore-sort)、[防彈出新分頁](https://github.com/JJptt1980/xxxx-no-popup) |

在子資料夾裡打 `/promo` 就會接著做下一步。
